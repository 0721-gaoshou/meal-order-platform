| 2026-11-08 | 本机无 Docker Desktop | 采用 WSL 内 Docker（29.9.2），不装 Desktop，避免冲突 |
| 2026-11-08 | 微信开发者工具"多端开发"功能 | 不使用；用户端 = 原生小程序，无独立 App |
| 2026-11-08 | IDEA 内下载 JDK 慢 | 改用清华 TUNA 镜像手动下载并登记 SDK |
| 2026-11-08 | MinIO 镜像被 daocloud/1ms/quay 等源全部拒绝（官方发布策略变化） | M0 先跑通 MySQL/Redis/RabbitMQ；MinIO 于 M1 前解决，备选方案：GitHub Releases 下载二进制在 WSL 原生运行 |
| 2026-11-08 | LeiBox 组件库检索评估 | 当前管理端任务无真实匹配（动效创意库），暂不接入；`otp-verification` 留作将来验证码登录候选 |
| 2026-11-08 | MinIO 停更确认（社区版 2025 末维护模式、Docker 镜像下架、仓库归档） | 对象存储切换为 **RustFS**（S3 兼容 + 端口约定与 MinIO 一致，daocloud 可拉）；后端统一用 AWS S3 SDK v2，生产可无缝切阿里云 OSS |
| 2026-11-08 | RustFS 控制台无法启用（env/flag 两种方式均不生效，且开启后主进程每约 16s 优雅退出） | 暂以 S3-only 模式运行（后端实际只需要 S3 API）；建桶由后端代码启动时管理，控制台等上游修复 |
| 2026-11-08 | Windows 本地安装了 MySQL80 服务（8.0.45，root/root123），接管 3306 端口 | dev 以本地 MySQL 为准；docker meal-mysql 保留但被遮蔽；`docker/init/schema.sql` 仍是唯一建表源，本地手动应用 |
| 2026-11-08 | WSL 虚拟机空闲自动关停，docker 四容器随之重启（表现为 `docker ps` 永远 "Up 1 second"），后端长跑时 RustFS/Redis 间歇不可达 | 长跑后端期间用 `wsl sleep` 保活；根治方案（未采用）：`.wslconfig` 调 `vmIdleTimeout` |
| 2026-11-08 | admin-web 响应拦截器成功时返回整个 AxiosResponse，token 实际存成 "undefined"（M0 `REQUIRE_AUTH=false` 掩盖） | 拦截器成功直接返回业务体，与 `<never, ApiResult<T>>` 调用约定对齐 |
| 2026-11-08 | LeiBox 接入决策更新（用户拍板 web 可用） | `transfer-glow` 接入批量上下架确认弹层（引擎适配 onConfirm 回调+中文文案）；上传反馈用 Element Plus 原生，不硬塞动效组件；`otp-verification` 仍留作验证码登录候选 |
| 2026-11-08 | 雪花 ID 超出 JS Number 安全整数 | 实体/VO id 字段 `@JsonSerialize(ToStringSerializer)` 全量字符串化；创建接口显式返回 String |
| 2026-11-09 | 购物车存储选型（MySQL 表 vs Redis） | **Redis Hash `cart:{userId}` 不落 MySQL**：读写频繁、可容忍极端丢失、Redis 已在栈内；数量以服务端为准防客户端篡改，价格不落车（列表回源、下单快照） |
| 2026-11-09 | 结算预览是否要做库存硬校验 | **不做**：预览只试算金额并发令牌，加购后库存可能已被他人买走，真实性由下单时 DB 条件更新兜底（§4.6）；预览报错反而误导用户 |
| 2026-11-09 | 重复提交与幂等的检查顺序 | 同 `requestId` 的**幂等回放放在令牌 DEL 之前**，重试不再消耗令牌；令牌只防"同一结算意图被并发提交"；`uk_request_id` 为最后兜底，并发穿透时 `setRollbackOnly` 回滚本次扣减再回放胜出单 |
| 2026-11-09 | Redis 与 DB 事务边界（下单后清购物车） | Redis 不进事务：用 `TransactionSynchronization.afterCommit` 提交后清理，失败仅告警——订单以 DB 为准，购物车残留属体验问题 |
| 2026-11-09 | MyBatis-Plus insert 不回读 DB 默认时间戳，创建响应 `createdAt` 为 null | 实体显式 `setCreatedAt/setUpdatedAt`（DDL 默认值保留作直连 SQL 的兜底） |
| 2026-11-09 | 小程序 UI 自动化验证受限（Skyline 下 `page.data(key)` 不可靠；窗口被遮挡时 `mp.screenshot()` 返回旧帧；无 `element.touchStart`） | 状态断言改走后端接口 + 截图前用 PowerShell 置前开发者工具窗口 + 手势用 `page.callMethod('onTouchStart', 合成事件)` 驱动；配方已记入交接文档 |
| 2026-11-09 | 小程序无 C 端商品接口与正式登录 | 暂用 `admin/spus/page` + 首页"开发者登录（admin）"占位，正式 `wx.login` + code2session 与 C 端接口在 M4/M6 补 |
